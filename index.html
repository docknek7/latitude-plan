FLAGSHIP PROJECT · PUBLIC PORTFOLIO + MICRO BUSINESS

PaperTrail · 可溯源的科研阅读助手

从你自己真正有需求的PDF学术阅读开始，逐步成为可以让其他研究生付费试用的工作流工具。

产品为什么值得做

用户上传/选择论文PDF → 选择一段文本 → 提问 → 返回带页码定位的解释 → 保存双语术语、公式上下文和复习卡片。重点不是“接个聊天API”，而是建立可验证引用、评估体系和数据管理流程。

现代技术栈（按阶段升级）

MVP React + TypeScript + PDF.js

本地打开PDF、选区高亮、页码定位、批注与JSON导出。先做无服务端版本。

AI v1 FastAPI + 结构化输出 + RAG

分块索引、检索、模型回答、返回证据来源；不做无法验证的随意引用。API密钥只存在服务端。

可靠性 Evaluation + Tracing + Cost tracking

建立至少30个问题的测试集，评测引用准确率、失败案例、延迟与单次成本。

产品化 账户 / 配额 / 支付 / 隐私

有付费需求后再引入鉴权、账单和后端数据库。不要先做重架构。
